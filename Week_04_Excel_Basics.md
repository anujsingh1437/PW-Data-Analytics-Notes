# Week 4: Introduction to Excel & Analyst Toolkit 📊

This file tracks the core concepts and notes covered during Week 4 of my Data Analytics program at PW Skills. The focus this week was on understanding the holistic analysis workflow and mastering the absolute foundations of Microsoft Excel.

## 🛠️ 1. The Analyst Toolkit Overview
Learned how different tools collaborate in a real-world data workflow to drive business decisions[cite: 3]:
* **SQL:** The standard language used to fetch and join large datasets from databases[cite: 3].
* **Excel / Python:** Used to clean, filter, and shape small-to-large datasets efficiently[cite: 3].
* **Statistics:** The framework used to interpret what the numbers mean correctly (e.g., correlation vs. causation)[cite: 3].
* **Power BI / Tableau:** Tools used to turn findings into interactive, shareable corporate dashboards[cite: 3].

## 🖥️ 2. Excel Architecture & UI Components
Mastered the core grid mechanics and structural interface of Microsoft Excel[cite: 1, 2]:
* **Workbook (.xlsx):** The entire saved Excel file[cite: 1, 2].
* **Worksheet (Sheet):** The individual tabbed pages inside a single workbook[cite: 1, 2].
* **Cell Grid:** A workspace structured by Columns (labelled with Letters) and Rows (labelled with Numbers)[cite: 1, 2].
* **Active Cell & Name Box:** The green-outlined selected cell; the Name Box displays its exact address (e.g., B4)[cite: 1, 2].
* **Formula Bar:** The area used to view and edit the exact value or formula inside an active cell[cite: 1, 2].

## ⚡ 3. Data Entry & Core Editing Mechanics
Practiced foundational data manipulation rules to ensure clean workflows[cite: 1]:
* **Data Types Alignment:** Excel automatically aligns Text to the left and Numbers/Dates to the right of a cell[cite: 1].
* **Formulas Rule:** Every formula or calculation must strictly begin with an `=` sign (e.g., `=A1+B1`)[cite: 1].
* **Efficiency Shortcuts & Tools:** 
  * `F2`: Edit the active cell instantly[cite: 1].
  * `Delete`: Clear cell content[cite: 1].
  * `Ctrl + Z` / `Ctrl + Y`: Undo and Redo actions[cite: 1].
  * **Fill Handle:** Dragging the bottom-right square corner of a cell to copy data or trigger AutoFill series (like months/days)[cite: 1].
